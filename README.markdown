# Beep 🐝

Beep is a responsive, minimalist, and fun To-Do List web app that helps you stay focused and get things done — one beep at a time.

## ✨ Features
- ➕ Add tasks
- ❌ Delete tasks
- ✅ Mark tasks as completed
- 🎨 Beautiful and responsive design
